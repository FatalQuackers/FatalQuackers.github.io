# FatalQuackers.github.io

Portfolio site for Quackers — live at https://fatalquackers.github.io

## Updating

Everything is in `index.html`. Near the bottom, in the `DATA` section of the script:

- `projects` — project cards (name, status `live`/`dev`/`past`, category `roblox`/`unreal`/`web`, blurb, tags, links). `latest: true` puts a card on the home page.
- `nowBuilding` — the scrolling "Now building" bar.
- `priceBuild` / `priceAnim` — pricing rows.
- `mediaData` — gallery files (add the file to the repo, then list it).

Pages can be linked directly: `#work`, `#testing`, `#gallery`, `#pricing`, `#contact`.
